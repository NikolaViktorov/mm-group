# ММ Груп

Официален уебсайт на **ММ Груп** – компания, предлагаща строителни, ремонтни и специализирани услуги в София и областта.

🌐 **Live Website:** https://mm-group-six.vercel.app/

## Технологии

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Lucide React

## Стартиране локално

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
